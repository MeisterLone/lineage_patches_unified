# LineageOS 23 integration fixes

These patches are in addition to the 265-patch tree produced by the 306-row A14-to-A16 port review.

## 9001 — Drop obsolete LGE vibrator HIDL build definition

The first LineageOS 23.2 `arm64_bgN` Soong bootstrap failed because
`vendor.lge.hardware.vibrator@1.0` inherits `android.hardware.vibrator@1.0`, which was removed from the
LineageOS/AOSP Android 16 `hardware/interfaces` tree. The FancyDay C10 does not use LGE vibrator interfaces.

The patch removes only the autogenerated Soong `Android.bp` definition for that unused extension. The `.hal`
source remains available for history, but Soong no longer attempts to resolve the deleted parent interface.

- Patch: `patches_treble/vendor_interfaces/9001-Drop-obsolete-LGE-vibrator-HIDL-build-definition.patch`
- A16 baseline: `TrebleDroid/vendor_interfaces@a2271d260e226e8de5cb1e8c15a229dc90c007dd`
- Patch SHA-256: `2bac28cf6a4e85615fb6d834abf94a20c6b477887f3535f4be735faa25f0151c`
- Validation: clean `git apply --check` on the recorded A16 baseline

## 9001 — Use Etar for the Lineage calendar dependency

The A16 `aosp_system_image` Soong filesystem definition requires a module named `Calendar`. LineageOS 23 no
longer syncs AOSP Calendar and provides Etar instead; every other dependency in the filesystem module exists.

The patch changes only that dependency from `Calendar` to `Etar`.

## 9002 — Mark Samsung framework HIDL interfaces generic

A16 generic-image dependency validation rejected Samsung radio and sysinput Java interfaces because their HIDL
roots were marked `system_ext_specific`, while retained TD framework patches link them from generic framework
modules. Their parent inheritance definitions had the same marker.

The patch removes only `system_ext_specific: true` from radio 2.0–2.2 and sysinput 1.0–1.2, making the complete
interface chains valid generic dependencies.

- Patch: `patches_treble/vendor_interfaces/9002-Mark-Samsung-framework-HIDL-interfaces-generic.patch`
- A16 post-integration baseline: `vendor/interfaces@f0f2718`
- Patch SHA-256: `2567cf092bc7a58581f63f21a9d056f5cafc479b37e3c7c9fa460106da0ab2f9`
- Validation target: A16 `aosp_shared_system_image` generic dependency closure

## 9030 — Keep the gamma annotation compile-time constant

The low-gamma patch makes `BrightnessUtils.GAMMA_SPACE_MAX` runtime-configurable (255 or 65535), so Kotlin can no
longer evaluate it inside `@IntRange`. The patch uses static upper bound `65535L`; low-gamma runtime values remain
inside that valid range.

- Patch: `patches_treble_td/platform_frameworks_base/9030-Keep-gamma-annotation-compile-time-constant.patch`

## 9040 — Complete C10 merged-partition identity

all expose the researched retail brand, manufacturer, model, device, and name without renaming the lunch target.
